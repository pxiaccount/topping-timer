### About
🍰 A sweet way to track your time!

---
### 🚀 Features

- **Customizable themes**: Choose from a variety of styles to match your vibe.
- **Upload Images**: Drop your favorite image here and see it on the site!
---
### ⚙️ Build

Clone the repo:

```bash
git clone https://github.com/pxiaccount/topping-timer.git
cd topping-timer
npm install
npm run dev
```
